# 3D (the return of Photoshop's 3D workspace)

> **Status:** new (2026-10-27) · **Crates:** `photocraft-three` (L0, standalone), `engine/src/cmd/three_d_cmds.rs`, `ui-egui/src/panels/three_d_ui.rs`

Adobe removed Photoshop's 3D features in 2023 (Photoshop 25), since they depended on OpenGL. PhotoCraft
brings that workflow back, built clean-room in pure Rust. There is no OpenGL and no GPU dependency: a
parallel CPU rasterizer draws the live preview, and a CPU ray tracer does the final render. Both run
everywhere PhotoCraft runs, the web build included.

## The model

A **3D layer** is a pixel layer that carries a scene (`Layer::scene3d`). Every scene edit re-renders
the layer's pixels, so the canvas, blend modes, masks, layer styles, filters, export and PSD all see
the current render. **3D › Render 3D Layer** ray traces the scene into the layer. **Rasterize 3D
Layer** keeps the pixels and drops the scene. `.pcraft` files save the full scene (objects, materials,
textures, lights, camera, environment, render settings). PSD files get the rendered pixels only, as a
plain pixel layer.

## Window › 3D panel

- **With a normal layer active:** the *Create New 3D Object* buttons.
- **With a 3D layer active:**
  - **3D tools:** Orbit, Roll, Pan, Slide and Scale act on the camera or the selected object. Drag in the panel's view, or on the canvas itself (turn off *Use 3D tools on the canvas* to paint on the layer instead). The scroll wheel slides the camera. Each drag is one undo step.
  - **Scene tree:** Environment, Scene, Current View, objects and lights, with visibility toggles, add, duplicate and delete.
  - **Properties for the selected node:**
    - **Object:** name, position, rotation and scale; cast and catch shadows; Invisible. For extrusions: depth, twist, taper, bend, shear, bevel width, angle, segments, contour (linear, round, cove, ring), sides and smoothing.
    - **Materials** (per slot, with a preview sphere and presets): diffuse, specular, illumination, ambient, shine, reflection, roughness, bump, opacity, refraction and normal map, plus UV scale and offset. Textures load from image files or from any layer.
    - **Light:** type, colour, intensity, shadow, softness, position and direction, hotspot and cone, falloff.
    - **Camera:** perspective or orthographic, field of view, distance, orbit, roll, target, depth of field, saved views.
    - **Environment:** global ambient; image-based light (sky and ground colours, or an equirectangular image), with intensity and rotation; ground-plane shadows, reflections and height; background (transparent, colour or environment).
    - **Scene:** style, exposure, preview antialiasing, ray-trace samples and bounces, cross section, light presets.

Every control runs an engine `3d.*` command (`3d.set`, `3d.navigate`, `3d.setTexture`, …). The CLI, the
control channel and MCP can therefore drive all of it. `3d.inspect` returns the scene as JSON.

## Rendering

| | Preview (live) | Render 3D Layer |
|---|---|---|
| Method | Scanline rasterizer, z-buffer, deferred shading | Ray tracer with a BVH |
| Shadows | PCF shadow maps (infinite and spot lights) | Every light, including point lights; soft shadows from the light's softness |
| Reflections | Environment only | Traced (rough reflections blur), ground-plane reflections |
| Transparency | Layer alpha | Refraction with index of refraction |
| Other | All render styles, supersampling 1–3× | Depth of field, 1–256 samples per pixel |

## Known limits

- 3D painting on textures (Photoshop's Paint on Target Texture) and UV editing aren't implemented. Paint on the texture's source layer instead, then use *From Layer* again.
- Extrusions have no inflation (Photoshop's Cap › Inflate).
- No skinning, animation or spherical panorama editing. glTF animations import in their rest pose.
- PSD files don't carry the scene, so the 3D layer opens in Photoshop as its rendered pixels.
